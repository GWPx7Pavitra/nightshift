              Servers

              Health checks shown in the top bar of your new tab. *.cre8ivize.com report real HTTP status; other hosts report reachable or down.

                Updates

                Nightshift updates itself from your private GitHub repo. It rewrites only the files that changed, in the folder it runs from, then restarts. Your screen time, to-dos and settings stay exactly as they are.

                Brave turns folder access off by default. Open brave://flags/#file-system-access-api, set it to Enabled, relaunch, then choose the folder here.

                Install updates automatically

                Downloads in the background when you open a new tab, and restarts once you’ve left Nightshift’s pages. Choose “Allow on every visit” when Chrome asks, or it’ll ask again next time.
